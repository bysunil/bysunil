**Receipt scanning and expense tracking**

A web application that uses Gemini OCR to extract text from receipts and store the resulting information in a database.

- 📸 Scan receipts and extract useful information with AI.
- 🗃️ Store and organize extracted receipt data.
- 📊 Make expense tracking more convenient.

**Tech:** React · Gemini OCR · Database

[![Live Demo](https://img.shields.io/badge/Live_Demo-Visit-2ea44f?style=for-the-badge&logo=netlify&logoColor=white)](https://dairytrack.netlify.app/)

**Community-driven credit card cashback information**

A platform for checking cashback benefits across credit cards, with community discussions to keep track of changing cashback structures.

- 💰 Compare cashback benefits.
- 🔎 Find relevant card offers and reward information.
- 💬 Discuss changes and updates with the community.

[![Visit CBack](https://img.shields.io/badge/Visit_CBack-Website-2ea44f?style=for-the-badge)](https://cback.netlify.app/)
